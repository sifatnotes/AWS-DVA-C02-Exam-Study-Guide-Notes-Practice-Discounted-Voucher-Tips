## Exam Overview

The **AWS Certified Developer – Associate (DVA-C02)** exam validates your technical expertise in building, testing, deploying, securing, and debugging cloud-native applications on Amazon Web Services.

| Parameter | Exam Specification |
| --- | --- |
| **Exam Code** | DVA-C02 |
| **Total Questions** | 65 (Multiple Choice & Multiple Response) |
| **Time Allowed** | 130 minutes |
| **Passing Score** | 720 / 1000 (Scaled Scoring) |
| **Delivery Method** | Pearson VUE (In-person or Online Proctored) |
| **Validity** | 3 Years |

---

## Who Should Take It

This certification is designed for software developers, backend engineers, cloud developers, and DevOps practitioners who build applications natively on AWS.

**Recommended Prerequisites:**
- At least 1 year of hands-on experience developing and maintaining AWS-based applications.
- Proficiency in at least one high-level programming language (Python, Node.js, Java, C#, Go).
- Familiarity with core AWS SDKs, AWS CLI, container concepts, and CI/CD pipelines.
